## 遊戲規則:## 🎴 遊戲規則說明 (Game Rules)

本專案實作了一套**標準日式三人麻將** 的核心精簡規則，規則摘要如下：

*   **牌總數 (108張)**：移除傳統四人麻將的「二萬至八萬」，僅保留一萬、九萬、所有索子（條）、筒子（餅）與字牌，加速遊戲節奏。
*   **起手配牌**：每局開局自動洗牌，並配發玩家 **13 張起手牌**，摸第 14 張牌後開啟回合。
*   **拔北機制 (Kita)**：三人麻將特有規則。手牌若有「北風」可隨時宣告拔北，牌面將移至副露區算台，系統並自動由牌山抽一張「嶺上牌」進行補牌。
*   **副露互動 (吃碰槓)**：
    *   **碰/槓牌**：模擬對手出牌時，系統自動偵測手牌數量（碰需 $\ge 2$ 張、槓需 $\ge 3$ 張），符合規則才開放玩家操作。
    *   **槓牌補牌**：當成功執行槓牌後，系統會自動由牌山抽取一張補牌。
*   **獲勝判定**：
    *   **自摸**：玩家回合摸牌時，若手牌與副露完美湊成「1對眼睛 + 4組面子（順子或刻子）」，即可宣告自摸獲勝。
    *   **榮和**：模擬對手出牌時，若對手打出的牌恰好能與手牌湊成胡牌牌型，即可宣告榮和（胡別人的牌）獲勝。
   

## 遊戲流程:## 🔄 遊戲核心運行流程 

遊戲的生命週期與控制流程由 `main.cpp` 的主迴圈驅動，核心流程分為以下三個階段：

### 1. 開局與初始化階段 
*   **牌山規格化**：調用 `deck.init()` 生成 108 張三人麻將特製牌組（剔除 2~8 萬）。
*   **隨機搓牌**：調用 `deck.shuffle()`，透過梅森旋轉演算法與時間戳進行高隨機性洗牌。
*   **起手發牌**：利用 `for` 迴圈**自動配發 13 張起手牌**給玩家，隨後摸取第 14 張牌開局。

### 2. 玩家回合主迴圈 
進入 `while(true)` 核心事件驅動迴圈，每輪自動理牌（`sortHand`）並印出狀態，玩家可輸入數字執行 4 大核心指令：
*   **按 1. 丟牌**：輸入想要打出的手牌編號，將牌打出並進入「對手互動階段」。
*   **按 2. 拔北**：若手牌有北風，則宣告拔北並觸發**狀態防呆檢查**，通過後自動由牌山摸牌補牌。
*   **按 3. 自摸**：啟動 AI 判定，檢查當前 14 張手牌是否符合胡牌牌型。符合則宣告勝利，否則返回選單。
*   **按 4. 離開**：直接強制中斷迴圈，安全結束遊戲。

### 3. 對手出牌與互動階段 
當玩家執行「丟牌」後，程式會自動切換進入迴圈，模擬兩位對手的出牌行為：
*   **對手隨機打牌**：螢幕顯示 `對手丟牌: X`。
*   **即時互動選單**：畫面上會即時詢問玩家是否執行 **1.碰、2.槓、3.榮和、4.不理**。
    *   **碰 / 槓**：系統會先調用 `canPong` / `canKong` 檢查手牌數量是否符合。若符合則執行搬移，槓牌會觸發補牌；不符合則噴出提示。
    *   **榮和**：透過虛擬測試技術判定是否能胡對手的牌。符合則宣告榮和勝利並結束遊戲。
*   **輪替摸牌**：若對手出牌滿兩輪玩家皆選「不理」，則自動由牌山摸一張新牌，重新回到「玩家回合」。
